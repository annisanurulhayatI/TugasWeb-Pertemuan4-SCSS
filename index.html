Tentang Saya

Haii, saya adalah mahasiswa Semester 3 Universitas Negeri Medan Program Studi Ilmu Komputer. Saya baru masuk ke dunia percodingan ketika mulai kuliah. Sebelumnya saya benar-benar tidak mengenal percodingan.

Walaupun begitu, saya mulai tertarik untuk mempelajarinya. Kepuasan yang saya rasakan ketika suatu projek akhirnya selesai membuat saya semakin penasaran dan ingin terus mengenal dunia percodingan lebih jauh.

Selain belajar coding, saya juga memiliki ketertarikan pada bidang kreatif seperti editing, photography, illustration, dan graphic design.
